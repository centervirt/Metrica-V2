# Metrica Dashboard V2

Plataforma integral de inteligencia financiera, control de monotributo, gestion comercial B2B y finanzas personales adaptada a la realidad economica argentina.

## Caracteristicas
- Dashboard Multidivisa ARS / USD MEP en tiempo real
- Copiloto IA Financiero & Vision OCR
- Modulo Negocios & Freelancers
- Termometro Fiscal de Monotributo con limites AFIP/ARCA
- Modulo Metrica Contador Partner B2B
- Pricing Bimonetario & Mobile-First

## Instalacion
`ash
git clone https://github.com/centervirt/Metrica-V2.git
cd Metrica-V2
npm install
cp .env.example .env
npm start
`
